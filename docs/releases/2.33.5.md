# ChatGPT Exporter 2.33.5

Date recorded in repository history: 25 August 2026.

## Status

Version `2.33.5` is present in `package.json` and the generated userscript metadata. The downstream repository does not currently contain a matching GitHub Release or `userscript-v2.33.5` tag, so this document records the verified repository version without claiming a formal published GitHub release.

## Changes

### All-conversations discovery

Version 2.33.5 fixes incomplete **All conversations** discovery introduced by the earlier Project filtering work.

- Wait for Project discovery before loading the All-conversations scope.
- Combine the normal ChatGPT conversation feed with every discovered Project feed.
- Deduplicate conversations by conversation identifier.
- Preserve existing **Not in a project** and specific-Project behaviour.
- Avoid the previous visible clear-and-reload cycle caused by Project discovery retriggering conversation loading.

Tracked by issue #68 and the implementation merged through pull request #69.

## Validation added

The repository added regression coverage for aggregate conversation discovery and deduplication. The fixture was subsequently made safe to run under Node.js so it could be included in the normal test suite.

Relevant follow-up commits include the conversation-discovery regression command and Node-safe regression fixture changes made on 25 August 2026.
