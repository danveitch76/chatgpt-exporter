# Roadmap

The live GitHub milestones and issues are authoritative. This document defines the capability sequence without duplicating volatile issue counts.

## Phase 1: File Discovery and Extraction

Delivered foundations include scanning, classification, inventory construction, deduplication, extraction statistics, embedded-data resolution, backend-path mapping, archive-limit planning and validation fixtures.

Remaining work includes live authenticated download, user-facing ZIP packaging, interruption recovery, preview and scope controls, browser-memory protection and end-to-end validation.

[Phase 1 milestone](https://github.com/danveitch76/chatgpt-exporter/milestone/1)

## Phase 1.5: Real Account Validation

Validation evidence is stored under [`docs/validation/phase-1-5`](./validation/phase-1-5/).

[Phase 1.5 milestone](https://github.com/danveitch76/chatgpt-exporter/milestone/2)

## Phase 2: Advanced Asset Recovery and Catalogue

Extends recovery and catalogue capabilities beyond straightforward uploaded files and embedded assets.

[Phase 2 milestone](https://github.com/danveitch76/chatgpt-exporter/milestone/3)

## Phase 3: Personal Archive and Knowledge Platform

Evolves conversation exports and recovered assets into a structured personal archive and knowledge platform.

[Phase 3 milestone](https://github.com/danveitch76/chatgpt-exporter/milestone/4)
